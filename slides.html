❌ The Challenge

Why Traditional LLM Agents Fail at ARC

Spatial hallucination, context exhaustion, and rigid schemas cripple standard prompting.

🛑 Raw Prompting & Blind Token Guessing
  • Spatial Blindness: Models hallucinate 2D Manhattan distances and miss diagonal wall blockages in raw text matrices.
  • Destructive Exploration: One wrong move into a trap or wall causes permanent failure; zero opportunity to test moves in sandbox memory.
  • Context Burnout: Printing raw board strings every single step rapidly overflows the 4k-32k context window.
🦆 The Duck Harness Solution
  • REPL Sandbox Workspace: The board is living state. The model can inspect variables, write loops, and calculate exact paths.
  • Action Chaining: Agent writes action(["UP", "UP", "RIGHT", "RIGHT"]) to execute full paths in 1 atomic turn.
  • Smart Memory Eviction: Keeps system prompt and hypothesis register while evicting stale intermediate turns.

🐍 LLM REPL Spatial Reasoning

Instead of hallucinating coordinates, the LLM executes exact Python queries: 

# Find all pushable boxes and target pads
boxes = [o for o in current_frame.segmentation 
         if o.color == 8]
targets = [o for o in current_frame.segmentation 
           if o.color == 6]

# Compute exact Manhattan distance
dist = abs(boxes[0].bbox[0] - targets[0].bbox[0]) + \
       abs(boxes[0].bbox[1] - targets[0].bbox[1])
print(f"Manhattan distance: {dist}")
✓ Zero distance calculation errors • Guaranteed collision boundary detection
🧠 Memory Architecture

World Model & Context Eviction Engine

Achieving indefinite play horizons without context window overflow.

📑 Explicit World Model Register

A structured hypothesis register preserved across all turns: 

# Persists across all agent turns:
World model:
- 'B' is player avatar
- '#' are impassable boundary walls
- 'C' is pushable block (displaces on contact)
- 'M' is target switch
- 'SPACE' toggles phase-door at (3,3)

The model can mutate and refine this text block at any time via standard Python variable assignment.

♻️ Dynamic Context Eviction (trim_messages)
Protected Invariants:
• System Prompt   • Current Board State   • World Model
Eviction Policy:
Intermediate observations (Turns 1...N-3) are trimmed when token threshold is reached, leaving only transition delta summaries.
🚀 Enables 100+ turns in small 8k/16k context models with zero degradation.
